# Translating Retro TV

The Flask/Jinja web interface uses gettext and Flask-Babel. English is the source
language, and Weblate can edit PO files without modifying application code.

## Weblate component settings

- File format: Gettext PO
- Template: `translations/messages.pot`
- File mask: `translations/*/LC_MESSAGES/messages.po`
- Source language: English (`en`)
- Translation language initially available: Hebrew (`he`)

## Updating and deploying translations

Install `pip install -r requirements.txt` and then run:

```sh
pybabel extract -F babel.cfg -o translations/messages.pot .
pybabel update -i translations/messages.pot -d translations
pybabel compile -d translations
```

Commit PO files, not the generated MO files. Recompile after Weblate updates.

The browser's Accept-Language selects the language, or set
`RETRO_TV_LANGUAGE=he` to force Hebrew. English is the fallback.
Hebrew changes the HTML document direction to RTL.

Jinja: `{{ _("Visible English text") }}`.
Browser JS: `gettext('Visible English text')`. No Python registry is required:
compiled PO translations are exported automatically to `window.TV_TRANSLATIONS`.
For parameters, use named placeholders, for example:
```js
notify(gettext('Channel %(number)s is playing', {number: channel}));
```
The PO translation can reorder placeholders without breaking the code.
Use `esc(gettext('Text'))` if inserting translated text into `innerHTML`,
or prefer `textContent` for safety.

### RTL and bidirectional text

The HTML root receives `dir="rtl"` when Hebrew is selected. Layout and text
normally inherit this direction. To override a single block, use `dir="ltr"`
for numbers, times, timeline grids and other fixed left-to-right UI, and
`dir="auto"` for a mixed-language title loaded from the library. Prefer CSS
logical properties such as `margin-inline-start`, `padding-inline-end`,
and `text-align: start` over hard-coded left/right. Do not mirror playback
progress, TV channel numbers, or the electronic program guide's time axis.

### Finding missed strings

1. Search in `templates/` for visible English. Wrap with
   `{{ _('English label') }}`, including placeholders and aria-labels.
2. Search in `static/js/` for `textContent`, `innerHTML`, `notify`,
   `alert`, and dynamically generated markup. Wrap visible strings in
   `gettext('English label')`.
3. Keep human-readable content separate from markup, API constants,
   selectors, CSS class names, and user media titles.
4. Run `pybabel extract -F babel.cfg -o translations/messages.pot .`, then
   `pybabel update -i translations/messages.pot -d translations`, translate
   in Weblate, and run `pybabel compile -d translations`.
5. Test with `RETRO_TV_LANGUAGE=he` (or an `Accept-Language: he` header).
   Check mobile and desktop layouts with longer strings and mixed-direction
   numbers.

Keep channel metadata, content titles and machine-readable API values as-is.

This first commit covers static server-rendered text and the initial shared JS
messages. Other runtime-generated JS labels, dedicated TV overlays, Android
companion resources, and styling adjustments require follow-up changes.
